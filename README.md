# creative-coding-A2

## DriftLines - TunePad
A music piece with both guitar and piano to create a calming atmosphere to help individuals that struggle with falling asleep. 

## Sources Used
- TunePad (Python Code)
- Miro (Journal)
- TunePad Resources/Documents
- YouTube (Tutorials)
